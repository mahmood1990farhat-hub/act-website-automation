ACT Customer CJK is a renamed subset of Noto Sans CJK SC Regular, distributed under the SIL Open Font License in OFL.txt.

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese

The subset covers the current ACT translation catalogues; customer-supplied names and addresses also use system font fallback. Rebuild after adding Chinese copy with scripts/build-customer-font.py in the frontend project.
